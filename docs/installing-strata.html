Install Strata

Open your usual Strata HTTPS address in a supported browser. Use the browser's install action to add Strata to your device. The app still needs an internet connection and the same account access as the website.

Chrome on a computer

  1. Open Strata in a regular Chrome window.
  2. Select the install icon in the address bar when offered, then confirm installation. The browser menu also provides installation options; wording varies by version.
  3. Launch Strata from your device's app launcher or Chrome's Apps page. Expect the Strata name, layers icon and a separate app window.

To remove the app, use its app menu or Chrome's Apps page. Review any option to remove site data before confirming.

Microsoft Edge on a computer

Open Strata and select the app installation icon when offered. Alternatively, use Settings and more, More tools, Apps, then Install this site as an app. Launch Strata from your device's app launcher. Manage or uninstall it from Edge's Apps page.

Phones and tablets

On supported Android browsers, open Strata and use the browser's Install app or Add to Home screen action. On iPhone or iPad, open Strata in Safari, use Share, then Add to Home Screen. If offered, enable Open as Web App. Confirm the name, then launch from the Home Screen.

Exact actions depend on your browser and operating system. A Home Screen shortcut may behave differently from a standalone installed app. Actual device installation must be checked on that device; a mobile-sized desktop window does not prove it.

Using the installed app

  • Sign in as usual. Installation does not grant an account, change permissions or bypass an expired session.
  • Close the app window, launch it again and refresh to confirm your normal Board workflows still work.
  • Sign out through your profile before leaving a shared device.
  • Installation does not provide offline editing or background synchronization.
  • If installation is unavailable, continue using Strata in a normal browser tab. Private browsing, organization policies and browser support can affect availability.

Canary and Production use different addresses. Installing one does not switch it to the other.
