# Quickstart: Card Attachment Actions

## Scenarios

1. Open any card modal and reveal the Attachments section.
2. Upload a browser-viewable file such as a `.png`, `.txt`, or `.pdf`.
3. Confirm the attachment row shows download, view, and remove actions in that order.
4. Use `View` and confirm the file opens in a new tab while the current Strata tab remains on the card.
5. Use `Download` and confirm the browser downloads the file with the stored filename.
6. Upload a non-viewable file such as `.fig` and confirm only download and remove are shown.
7. Add a link attachment and confirm the existing link opening flow still works.
