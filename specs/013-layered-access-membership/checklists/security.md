# Security Requirements Checklist

- [x] SEC001 - Are global, parent, resource, and membership authority sources separately defined? [Completeness]
- [x] SEC002 - Are scoped delegation and anti-escalation boundaries explicit? [Coverage]
- [x] SEC003 - Are server-side denials required independently of UI visibility? [Clarity]
- [x] SEC004 - Are session invalidation conditions complete for every authorization change? [Coverage]
- [x] SEC005 - Are last-System-Administrator safeguards explicit? [Coverage]
- [x] SEC006 - Are atomicity, unknown identifiers, duplicates, and partial-failure behavior specified? [Completeness]
- [x] SEC007 - Are audit actor, target, scope, outcome, and secret-exclusion requirements explicit? [Clarity]
- [x] SEC008 - Are deletion cascades bounded to prevent unrelated privilege loss? [Coverage]
- [x] SEC009 - Does migration preserve effective access while eliminating legacy authority sources? [Consistency]
- [x] SEC010 - Are inactive and already-member users excluded from add-member results? [Coverage]
