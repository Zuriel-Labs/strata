Issue #36 Implementation Plan

Deliver the approved Strata pipeline bootstrap from the clean origin/main baseline through repository validation, pull request, immutable Canary deployment, and PM review. Production remains gated.

Architecture decisions

  • AGENTS.md is canonical; Claude and Gemini files contain imports only.
  • Project #2 is the live metadata authority. The health script discovers and validates exact fields instead of copying opaque IDs.
  • Workflow skills are Strata-specific; shared design skills retain upstream provenance.
  • Release verification models one Express container, /api/health, ephemeral Canary SQLite, persistent Production SQLite, and backup state.
  • No branch protection or ruleset. Squash-only merge settings and CI evidence remain required by policy.
  • Human-facing artifacts use self-contained Dark Mode HTML, so this plan intentionally uses tasks/plan.html instead of the generic Markdown convention.
